# Neovim — Python IDE

Built upon [BreadOnPenguins/nvim](https://github.com/BreadOnPenguins/nvim) configuration to be my personal IDE for python development.

Key tools: **snacks.nvim** UI & explorer, **copilot** inline suggestions, **nvim-cmp** + LSP, **fzf-lua**, **gitsigns**, **indent-blankline**, **alpha-nvim** dashboard.
